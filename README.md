# Custom Finance

<h3>Este app foi criado com o foco de atender a demanda pessoal de ter uma gestao financeira mensal customizada para mim mesmo.</h3>

# Ferramentas

- Git
- Dart
- Flutter
- Realtime Database (Firebase)


# Como instalar?

<h2>1º forma: Baxar via tags a versão testada e homologada</h2>

<h3>Link da paginad do app:</h3>

<h4><a>https://github.com/Kyra4code/Finance-Controll/releases/</a></h4>

---

<h2>2º forma: Via repositório (Obrigatoriamente das ferramentas)</h2>

<h4>Clonando repositório:</h4>

````
git clone https://github.com/Kyra4code/Finance-Controll.git
````
<h4>Entrando no app</h4>

````
cd Finance-Controll
````

<h4>Baixando dependecias do flutter:</h4>

````
flutter pub get
````

<h4>Rodando debug</h4>

````
flutter run
````
